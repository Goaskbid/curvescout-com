# CurveScout

CurveScout helps motorcycle riders discover roads worth riding.

The platform evaluates route geometry, scenery, elevation, road quality, fuel availability, and safety considerations to create enjoyable rides.

## Features

- Route planning
- Scenic road discovery
- Elevation profiles
- Fuel stop planning
- Road quality scoring
- Safety information
- Waypoint generation
- GPS navigation support

## Who Uses CurveScout

- Motorcycle riders
- Touring riders
- Adventure riders
- Road trip enthusiasts
