# CurveScout.com v1.4.5 GitHub Pages Deployment 1. Download `curvescout_com_v1_4_5_github_deploy.zip`. 2. Unzip it locally. 3. Create or open the GitHub repository for CurveScout.com. 4. Upload all unzipped files to the repository root. 5. Commit to `main`. 6. In GitHub, open **Settings → Pages**. 7. Set **Build and deployment → Source** to **GitHub Actions**. 8. Push to `main` or run the included workflow from the Actions tab. 9. Keep the included `CNAME` file for `curvescout.com` if the domain is ready. 10. Test after deployment: search Zurich, Hamburg, Kiel and Berlin; open a selected route; scroll to Roadbook; verify road sections/checkpoints and Google/OSM/GPX actions. ## Local test ```bash npm test python3 -m http.server 8080 ``` Open `http://localhost:8080`.
