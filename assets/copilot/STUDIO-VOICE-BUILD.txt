How cs-studio-worker.js is built (its complete corresponding source under GPL-3.0-or-later)

Sources in this folder, as they are in the CurveScout project:
  cs-studio-worker.src.mjs  = src/copilot-live/studio-worker.mjs
  cs-g2p-local.src.mjs      = src/copilot-live/g2p-local.mjs
  cs-phon.src.mjs           = src/copilot-live/phon.mjs
  cs-build-copilot.src.mjs  = tools/build-copilot.mjs (this build script)

Dependencies (npm, exact versions): onnxruntime-web@1.22.0, phonemizer@1.2.1, kokoro-js@1.2.1; bundler esbuild@0.24.0.

Rebuild:
  1. put the four .src.mjs files back at the paths above (the imports name ./phon.mjs and ./g2p-local.mjs)
  2. npm install onnxruntime-web@1.22.0 phonemizer@1.2.1 kokoro-js@1.2.1 esbuild@0.24.0
  3. esbuild src/copilot-live/studio-worker.mjs --bundle --format=esm --platform=browser --target=es2020 --minify --legal-comments=inline --outfile=cs-studio-worker.js

Which part of cs-studio-worker.js comes from which source (r31 legal review: map the eSpeak-derived binary)
  - CurveScout code (GPL-3.0-or-later as part of this work): the three .src.mjs modules above.
  - eSpeak NG (GPL-3.0-or-later), compiled to WebAssembly: the base64 block "WORKER_DATA" and the espeak-ng-data
    files inside it come unchanged from phonemizer@1.2.1, files src/espeakng.worker.js and data/espeakng.worker.data
    (github.com/xenova/phonemizer.js, commit 6835144 "Update to v1.2.1"). A snapshot of that repository at that
    commit is cs-phonemizer-1.2.1-upstream.zip in this folder. The C source it was compiled from is eSpeak NG,
    github.com/espeak-ng/espeak-ng (GPL-3.0-or-later).
  - phonemizer.js glue (Apache-2.0), kokoro-js (Apache-2.0), onnxruntime-web (MIT, also cs-ort-*.bin and cs-ort-glue.js),
    voice files cs-voice-*.bin (Kokoro-82M, Apache-2.0): see STUDIO-VOICE-LICENSES.txt.
  CurveScout made no change to the eSpeak NG binary or its data.
